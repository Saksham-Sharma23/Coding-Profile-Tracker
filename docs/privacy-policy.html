Privacy Policy for Coding Profile Tracker

Last updated: September 2, 2026

Coding Profile Tracker ("the Extension") is a Chrome extension that helps users track their coding progress across supported competitive-programming platforms, including LeetCode, Codeforces, HackerRank, CodeChef, and GeeksforGeeks.

This Privacy Policy explains what information the Extension handles, how that information is used, where that information is stored, and when information is transmitted to third parties.

1. Information the Extension Handles

Coding profile information

The Extension may handle coding-related information from supported platforms, including:

  • Coding-platform usernames or profile identifiers
  • Problem-solving statistics
  • Ratings and rankings
  • Solved-problem information
  • Coding activity and progress
  • Submission-related information
  • Profile and historical progress information

This information is used solely to provide the Extension's coding-progress tracking features.

Website content

When you use the Extension on supported coding websites, it may read relevant website content needed to identify your coding profile, retrieve coding statistics, track progress, and provide the Extension's features.

The Extension does not intentionally collect unrelated browsing activity or general web-browsing history.

Extension settings and locally stored data

The Extension stores information locally in your browser, which may include:

  • Coding-platform usernames and detected profile information
  • Coding statistics and historical snapshots
  • Solved-problem and submission-related data
  • User preferences and settings
  • Coding goals and reminder settings
  • GitHub synchronization settings
  • GitHub account and repository information
  • Information needed to manage queued or previously synchronized solutions

This information is stored using Chrome's extension storage facilities and is used to provide the Extension's functionality.

2. GitHub Synchronization

GitHub synchronization is an optional feature.

If you choose to connect GitHub and enable synchronization, the Extension can save accepted LeetCode solutions to a GitHub repository that you select.

Depending on the features you use, information sent to GitHub may include:

  • Your GitHub account information needed to identify the connected account
  • Repository information for the repository you select
  • Accepted LeetCode solution code
  • Associated LeetCode problem information, such as the problem name, description, and related solution information

Nothing is sent to GitHub for synchronization unless you choose to connect a GitHub account and enable the relevant synchronization feature.

The Extension does not choose a repository on your behalf. You control which repository is used for synchronization.

3. GitHub Authentication Information

When you connect GitHub, the Extension handles authentication information required to access the GitHub account and repository functionality that you authorize.

Authentication information is stored locally in the browser and is not sent to a server operated by the developer.

The Extension uses GitHub's authentication mechanisms to obtain the authorization necessary for the GitHub features you choose to use.

You can disconnect GitHub from the Extension. When the Extension disconnects a GitHub account, locally stored GitHub authentication information associated with the connection is removed according to the Extension's implementation.

Your GitHub account remains subject to GitHub's own terms and privacy policies.

4. How Information Is Used

Information handled by the Extension is used only to provide its stated functionality, including:

  • Displaying coding progress in the Extension dashboard
  • Tracking coding statistics and historical progress
  • Detecting supported coding profiles
  • Providing coding reminders and notifications
  • Providing the Chrome side-panel experience
  • Maintaining locally stored coding history and settings
  • Providing optional GitHub synchronization when enabled by the user

The Extension does not use the information it handles for advertising, creditworthiness decisions, lending decisions, or unrelated profiling.

5. Where Information Is Stored

Coding-profile information and Extension settings are primarily stored locally in your Chrome browser using Chrome's extension storage facilities.

The developer does not operate a server that receives and stores your coding-profile data.

GitHub synchronization is an exception. When you explicitly enable GitHub synchronization, selected information is transmitted directly to GitHub so that the Extension can perform the synchronization feature you requested.

6. Information Sharing and Third Parties

The Extension does not sell your personal information.

The Extension does not transfer user data to third parties for advertising or unrelated purposes.

The primary third-party service involved in data transmission is GitHub, and only when you choose to use the optional GitHub synchronization feature.

When GitHub synchronization is enabled, information necessary to perform the requested synchronization is transmitted to GitHub and stored in the GitHub repository you select.

The Extension does not use third-party advertising networks or analytics services to track users.

7. Data Security

The Extension is designed to minimize data transmission and keep coding-profile information locally in the user's browser whenever possible.

Communications with supported online services and GitHub use HTTPS connections where applicable.

Users should protect their Chrome profile and GitHub account and should only connect repositories they are comfortable using for synchronization.

No method of electronic storage or transmission can be guaranteed to be completely secure. The Extension therefore cannot guarantee absolute security of information.

8. Data Retention and Deletion

Because most Extension data is stored locally in your browser, you can remove locally stored Extension data by removing the Extension or clearing its stored data through Chrome.

You can also disconnect GitHub from the Extension to stop GitHub synchronization and remove the locally stored GitHub connection information handled by the Extension.

Data that has already been synchronized to a GitHub repository is controlled by the user through GitHub. Disconnecting the Extension does not automatically delete files that were previously uploaded to a GitHub repository.

To delete synchronized files from GitHub, you must remove them from the relevant GitHub repository.

9. No Account Required

Coding Profile Tracker does not require users to create an account with the developer or provide personal information to the developer in order to use its core coding-progress tracking functionality.

An optional GitHub connection is required only if you choose to use GitHub synchronization.

10. Children's Privacy

The Extension is not specifically directed toward children and does not knowingly collect personal information from children for advertising or profiling purposes.

11. Changes to This Privacy Policy

This Privacy Policy may be updated when the Extension's functionality or data practices change.

If material changes are made, the updated policy will be published at this URL and the "Last updated" date will be changed accordingly.

Users should periodically review this Privacy Policy to remain informed about how the Extension handles information.

12. Contact

If you have questions, concerns, or requests regarding this Privacy Policy or the privacy practices of Coding Profile Tracker, please contact the developer through the contact information provided on the Chrome Web Store listing for the Extension.
